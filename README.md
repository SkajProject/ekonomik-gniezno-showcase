# Zespół Szkół Ekonomicznych w Gnieźnie: strona szkoły

> 🔒 Kod i konfiguracja strony należą do szkoły i nie są publikowane. To repozytorium pokazuje efekt pracy.

![Strona Zespołu Szkół Ekonomicznych w Gnieźnie](assets/ekonomik.jpg)

**Strona publiczna szkoły ponadpodstawowej w Gnieźnie.** Oferta kształcenia, nabór, aktualności, galerie i dokumenty w jednym miejscu.

🌐 [ekonomik.gniezno.pl](https://ekonomik.gniezno.pl)

## Co zawiera

- Oferta edukacyjna: kierunki technikum
- Nabór: zasady rekrutacji i link do systemu naboru
- Aktualności, archiwum, galerie zdjęć, 120-lecie szkoły, projekty
- Sekcje „Dla uczniów” i „O szkole” z dokumentami
- Panel opcji dostępności (m.in. powiększenie tekstu, wysoki kontrast)
- Link do dziennika elektronicznego, profile w mediach społecznościowych

## Stack

WordPress

## Mój udział

Stronę zrobiłem razem z Igorem Dobrzyńskim (stopka strony wymienia nas obu). Pracowaliśmy nad wszystkim wspólnie, bez podziału na osobne obszary.
